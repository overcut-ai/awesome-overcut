# AGENTS.md

## 📋 Project Overview
- Monorepo with two npm apps under `apps/` generated by Amplication.
- **Server**: NestJS API exposing REST (`/api/*`) and GraphQL (`/graphql`) with Prisma + PostgreSQL.
- **Admin UI**: React + React-Admin client (Vite) consuming the GraphQL API.

**Primary tech**: Node.js, TypeScript, NestJS, Prisma, PostgreSQL, GraphQL, React, React-Admin, Vite, Docker Compose.

## 🧭 Development Guidelines
### Prerequisites
- Node.js >= 16
- npm >= 8
- Docker + Docker Compose (recommended)

### Install dependencies
```bash
cd apps/hotel-management-service-server && npm install
cd ../hotel-management-service-admin && npm install
```

### Run with Docker Compose (recommended)
```bash
cd apps/hotel-management-service-server
npm run compose:up
```
- GraphQL: `http://localhost:3000/graphql`
- Swagger UI: `http://localhost:3000/api`
- Admin UI (start separately): `http://localhost:3001`

Stop containers:
```bash
npm run compose:down
```

### Run apps individually
```bash
# server
cd apps/hotel-management-service-server
npm run prisma:generate
npm run db:init
npm run start

# admin (new terminal)
cd apps/hotel-management-service-admin
npm run start
```
Default dev credentials:
```
Username: admin
Password: admin
```

## 🧩 Code Patterns
### Server (NestJS + Prisma)
- Feature modules (hotel/room/reservation/customer) extend generated base classes in `base/`.
- To customize behavior, edit the non-`base/` files (e.g., `hotel.controller.ts`, `hotel.resolver.ts`) rather than generated base files.
- REST endpoints are under `/api/*`; GraphQL schema is auto-generated (`schema.graphql`).

### Admin UI (React-Admin)
- Data provider uses Apollo + `ra-data-graphql-amplication`.
- Auth provider stores bearer token in localStorage.
- CRUD screens live under `src/<entity>/` (hotel, room, reservation, customer).

## ✅ Quality Standards
- Keep `.env` values aligned with the app expectations.
- Regenerate Prisma client after schema changes:
  ```bash
  npm run prisma:generate
  ```
- Run server tests with Jest:
  ```bash
  npm run test
  ```
- Admin UI has lint and type-check scripts:
  ```bash
  npm run lint
  npm run type-check
  ```

## ⚠️ Critical Rules
- Do **not** edit generated files under `apps/hotel-management-service-server/src/**/base/` directly; extend in non-base classes instead.
- Run migrations before relying on schema changes:
  ```bash
  npx prisma migrate dev --name <migration_name>
  ```
- Run commands from the correct app directory (each app has its own `package.json`).
